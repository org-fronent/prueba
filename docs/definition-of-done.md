# 🎯 Definition of Done (DoD)

Para considerar una Historia de Usuario o funcionalidad como **COMPLETADA (Done)**, debe cumplir estrictamente con los siguientes puntos:

1. **Código:**
   - Debe compilares/ejecutarse sin errores ni advertencias graves.
   - Debe cumplir con las convenciones de nomenclatura del equipo.

2. **Control de Versiones:**
   - La rama ha sido sincronizada con `main`.
   - El Pull Request tiene la aprobación requerida en `CODEOWNERS`.

3. **Pruebas y Documentación:**
   - Se verificaron todos los Criterios de Aceptación.
   - El archivo `README.md` o documentación dentro de `docs/` se actualizó de ser necesario.
